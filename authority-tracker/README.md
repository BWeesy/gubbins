# authority-tracker

Web pages for BWeesy's Authority Tracker, the Android app (its code is in a
separate, private repository).

- `privacy/` is the app's privacy policy, published at
  <https://bweesy.github.io/gubbins/authority-tracker/privacy/>. The app's About
  screen and its Google Play listing link to it.
